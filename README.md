# Machine Learning Modelling of Spectroscopic Measurements of Pharmaceuticals

## MSc Pharmaceutical Science – University of Surrey

This repository contains retrospectively reconstructed MATLAB scripts
and supporting documentation for an MSc research project investigating
the prediction of active pharmaceutical ingredient (API) concentration
in pharmaceutical tablets using Near-Infrared (NIR) and Fourier-transform
Raman spectroscopy.

## Author

Rishikesh Prasad

## Supervisor

## Methods

The analysis included:

- Spectral preprocessing
- Principal Component Analysis
- Q-residual analysis
- Kennard-Stone sample selection
- Partial Least Squares Regression
- Support Vector Regression
- Independent test-set evaluation
- Residual analysis

## Important note

The original historical MATLAB scripts were not retained. The MATLAB
scripts in this repository were reconstructed retrospectively from the
final project workflow and retained MATLAB workspace outputs to document
the analytical procedure.

The original spectroscopic datasets are not redistributed in this
repository.
